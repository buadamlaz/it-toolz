# Changelog

All notable changes to IT-ToolZ for users. Newest first. Dates are in ISO format (YYYY-MM-DD).

Türkçe: [CHANGELOG.tr.md](CHANGELOG.tr.md)

## 1.0.1 — 2026-10-28 (closed testing on Google Play)

### Added
- **DNS Lookup: choose the DNS server.** Ask your device's DNS (default), **1.1.1.1**, **8.8.8.8** or a server IP address you enter, like `nslookup example.com 1.1.1.1`. The result shows which server answered and whether UDP or TCP was used. Your last choice is remembered on the device.
- **Public IP and RDAP/WHOIS: open coordinates in your maps app.** Tap the coordinates (or the pin icon next to them) to see the approximate location in the maps app of your device; on iPhone in Apple Maps.

### Changed
- **IP details tables** (network, location, time zone): labels on the left, values aligned on the right; long values such as provider names wrap neatly on the right.

## 1.0.0 — 2026-10-22

First release.

- 19 tools: Ping, Traceroute, DNS Lookup, Reverse DNS, Port Check (TCP and UDP), Subnet Calculator, IP Converter, Public IP, NTP Time Checker, Wake-on-LAN, LAN Device Discovery, SSL Certificate Checker, RDAP/WHOIS, Password Generator, HTTP Headers, Hash Generator, Base64, URL Encoder/Decoder and JSON Formatter.
- My Network page, favorites, history with re-run.
- Light, dark and system themes; 7 languages.
