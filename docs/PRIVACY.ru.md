## 1. О приложении
IT-ToolZ — набор инструментов для IT- и сетевых специалистов. Приложение выполняет сетевую диагностику (Ping, Traceroute, DNS Lookup, Reverse DNS, Port Check, NTP Time Checker, SSL Certificate Checker, HTTP Headers, RDAP/WHOIS, Public IP), предлагает инструменты для локальной сети (Wake-on-LAN, LAN Device Discovery), офлайн-калькуляторы и конвертеры (Subnet Calculator, IP Converter, Base64, URL Encoder/Decoder, JSON Formatter, Hash Generator для текста, Password Generator) и показывает сведения о вашем текущем сетевом подключении («Моя сеть»).

В IT-ToolZ нет учётных записей, аналитики, отчётов о сбоях, рекламы и собственного сервера. **Издатель не получает из приложения никаких данных.**

## 2. Данные, хранящиеся на вашем устройстве
- **История** запусков сетевых инструментов (например, проверенный хост, статус результата и время; для Wake-on-LAN — введённый MAC-адрес; для LAN Device Discovery — только просканированный диапазон и число найденных устройств), **избранное** (какие инструменты и в каком порядке) и **настройки** (язык, тема, параметры Password Generator) хранятся только в закрытом хранилище приложения на вашем устройстве.
- История никогда не содержит паролей, токенов, cookie, учётных данных в URL и параметров запроса URL. Password Generator, Hash Generator, Base64, URL Encoder/Decoder и JSON Formatter никогда ничего не записывают в историю.
- Сведения на странице «Моя сеть» и результаты Public IP не сохраняются.
- **Резервные копии:** данные приложения исключены из облачного резервного копирования Android и из переноса с устройства на устройство. Они остаются только на этом устройстве.
- **Удаление данных:** вы можете удалить одну запись истории (долгое нажатие) или всю историю (Настройки > Данные > Очистить историю). Очистка данных приложения в настройках Android или удаление приложения удаляет все его данные. Поскольку у издателя нет никаких копий, удалять больше нечего.

## 3. Данные, передаваемые по сети
Приложение обращается к интернету, только когда вы запускаете сетевой инструмент или нажимаете кнопку, которая этого требует.

- **Выбранные вами адресаты.** Ping, Traceroute, Port Check, NTP Time Checker, SSL Certificate Checker и HTTP Headers подключаются к введённому вами хосту, адресу или URL (HTTP Headers также следует перенаправлениям). Как и при любом подключении к интернету, адресат видит IP-адрес вашего устройства; при Traceroute тестовые пакеты видят также маршрутизаторы на пути. SSL Certificate Checker передаёт во время TLS-рукопожатия только имя хоста и никаких других данных. HTTP Headers отправляет по одному запросу на адрес без cookie и данных для входа; обычные адреса `http://` не шифруются.
- **Ваша локальная сеть.** Wake-on-LAN отправляет «magic packet» (UDP) с введённым MAC-адресом на выбранный вами адрес, обычно в вашей локальной сети. LAN Device Discovery сканирует только выбранный вами диапазон локальной сети (только частные диапазоны адресов) с помощью ICMP echo и попыток TCP-подключения и запрашивает имена устройств у вашего DNS-резолвера. Списки устройств показываются на экране, не сохраняются и никуда не отправляются.
- **DNS.** DNS Lookup и Reverse DNS отправляют введённое имя или адрес DNS-резолверу вашего устройства (DNS-серверу вашей сети, провайдеру частного DNS или вашему VPN). DNS-запросы обычно не шифруются, если не включён частный DNS. В DNS Lookup можно вместо этого выбрать DNS-сервер самостоятельно (1.1.1.1 от Cloudflare, 8.8.8.8 от Google или свой адрес): тогда запрос идёт напрямую на этот сервер через порт 53 без шифрования, в обход частного DNS и настроек DNS устройства. Приложение запоминает ваш последний выбор только на устройстве.
- **RDAP/WHOIS.** Для доменного имени приложение загружает общедоступные списки IANA (data.iana.org; эти запросы не содержат вашего запроса) и затем обращается к реестру, отвечающему за этот домен (например, Verisign). Для IP-адреса приложение обращается к стороннему сервису **ipwho.is**, который возвращает приблизительное местоположение и сетевого провайдера адреса. Реестр или ipwho.is получает ваш запрос и ваш IP-адрес. Частные и локальные адреса (например, 192.168.x.x) никогда не отправляются.
- **Public IP.** Чтобы показать ваш публичный IP-адрес с сетевым провайдером и приблизительным местоположением, приложение обращается к стороннему сервису **ipwho.is**. Только если ipwho.is недоступен, приложение одновременно обращается к двум другим сторонним сервисам: **ipify** (api.ipify.org, api6.ipify.org) и **ifconfig.me**. Каждый опрошенный сервис получает ваш публичный IP-адрес; кроме языка приложения (для названий мест), никакие другие данные не передаются. Это происходит только при нажатии кнопки в инструменте Public IP или на странице «Моя сеть». Если вы нажмёте на приблизительные координаты IP-адреса, они передаются в картографическое приложение вашего устройства (на iPhone — Apple Карты); само приложение ничего не отправляет.

Эти адресаты управляются третьими лицами и обрабатывают запросы в соответствии со своими политиками конфиденциальности. Приложение не использует ваш IP-адрес для определения вашего местоположения.

## 4. Разрешения
- **Интернет, состояние сети** — для работы сетевых инструментов и отображения текущего подключения.
- **Состояние Wi-Fi** — для отображения частоты, уровня сигнала и скорости соединения Wi-Fi на странице «Моя сеть».
- **Локальная сеть (iOS)** — iOS запрашивает разрешение, прежде чем приложение сможет обращаться к устройствам в вашей локальной сети (Wake-on-LAN). Оно используется только для запущенного вами инструмента.
- **Местоположение (необязательно)** — Android показывает имя подключённой сети Wi-Fi (SSID/BSSID) только приложениям с доступом к точному местоположению. IT-ToolZ запрашивает это разрешение, только когда вы нажимаете кнопку на странице «Моя сеть». Имя сети показывается на экране и никогда не сохраняется и не отправляется. Приложение никогда не считывает ваше местоположение. Всё остальное работает без этого разрешения.

Приложение не обращается к вашему номеру телефона, контактам, сообщениям, файлам, камере или микрофону и не считывает идентификаторы SIM-карты и устройства (IMSI, ICCID, IMEI).

## 5. Буфер обмена
Когда вы копируете значение, оно помещается в буфер обмена устройства, где его могут прочитать другие приложения или клавиатура. Пароли, скопированные из Password Generator, помечаются как конфиденциальные, поэтому Android 13 и новее скрывают их в предпросмотре буфера обмена. «Очистить буфер обмена» удаляет скопированный пароль, только если он всё ещё находится в буфере обмена; то, что вы скопировали позже, не затрагивается. Приложение не читает содержимое вашего буфера обмена.

## 6. Password Generator
Пароли создаются на вашем устройстве с помощью защищённого системного источника случайных чисел. Они никогда не сохраняются, не записываются в журналы, не отправляются и не попадают в историю. Пока Password Generator открыт, Android блокирует снимки и запись экрана и скрывает его в списке недавних приложений.

## 7. Дети
IT-ToolZ — профессиональный инструмент, не предназначенный для детей.

## 8. Изменения
Если эта политика изменится, новая версия будет опубликована по этому адресу с новой датой вступления в силу.
